# 实现来源与贡献边界

本仓库是实习经验的独立公开演示实现。它不是公司源码的脱敏复制，没有继承公司Git历史，没有使用公司模板、部署信息、登录态或真实业务数据。

可追溯的思考是：采集成功不一定意味着业务数据可信；数据质量检查应放在写入之前；重复请求和人工重跑需要不同语义；模型的建议不能直接成为执行授权。

代码、演示表、SKU、页面、参考样本和故障场景在本仓库重新设计，使用Java/Spring Boot、FastAPI和Vue等已有技术。为方便别人复现，公开演示数据库使用H2文件，没有宣称它就是公司生产环境。

实现由AI协作完成。面试时应依据实际参与范围说明场景定义、设计选择、代码修改、验证和复核，不将“仓库属于个人账号”等同于“所有代码均手工独立编写”。

## 与其他项目的关系

本阶段只解决库存数据准备和受控查询，不连接个人供应链补货/表单项目，也不连接CRM。后续项目可消费经过核实的运营事实，但只有真实接通后才能声称运行时集成。

公开演示可用于解释实习中的设计取舍，不作为公司上线时间、业务规模或收益的直接证据。
