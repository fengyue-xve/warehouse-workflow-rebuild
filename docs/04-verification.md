# 验收记录与结论边界

本地验收日期：2026-10-20。

| 层次 | 结果 | 实际证明 |
| --- | --- | --- |
| Java 集成/传输测试 | 26项通过 | 会话/预检隔离、权限、预检差异、拒写、并发确认、事务回滚、历史保留、进程中断恢复、HTTP传输契约 |
| Python 测试 | 18项通过 | 合成导出、服务认证、只读白名单、规则优先、工具消息协议、轮次上限与缺证据处理 |
| 双服务 HTTP | 24项检查通过 | 真Java与FastAPI进程互调、真实H2文件、拒写、重试、实际停止Python后的失败记录、Java进程重启保留数据 |
| 浏览器 | 8项检查通过 | 登录、空导出预检、明确确认、失败重试、页面刷新、真实规则查询、viewer边界、移动端无整页横向溢出 |
| Vue | 构建通过 | 可由Java同一入口提供静态页面 |

这些层次有覆盖重叠，不相加成业务“准确率”。命令见仓库README；可机器读取的HTTP和浏览器结果在运行后的 `artifacts/`，不把临时数据库、登录凭证或进程日志提交到Git。

Java单测和MockMvc测试中的导出服务使用替身；真实HTTP套件使用实际导出服务，因此曾发现并修复JDK HTTP客户端的协议升级兼容问题。传输回归已单独覆盖HTTP/1.1。

事务失败测试向测试H2增加临时约束，真实触发提交路径异常，检查库存回滚、成功审计不存在、失败任务保留；它没有通过伪造成功响应掩盖失败。
